# Changelog

All notable changes to this project are documented here.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

### Added

- `make lock` generates `requirements-lock.txt` with `uv pip compile`; releases younger than 14 days are skipped unless `LOCK_MIN_RELEASE_AGE_DAYS=0` is passed.
- Guidance on the assignment expression `:=` in `CONTRIBUTING.md`.
- `scripts/check_test_layout.py`, shared with the other repository and run by `make lint`, requires every unit test file to mirror a production unit (`tests/unit/<dirs>/test_<name>.py`) or to live in `tests/unit/project/` or `tests/unit/scripts/`. `tests/layout_pending.txt` may list multi-unit files that are still to be split; the list only shrinks, and it is currently absent because no file is pending.
- `audiodoc.errors.djvu` and `audiodoc.errors.images` hold the client-safe DJVU and OCR errors as public classes (for example `DjvuTooManyPagesError`, `ImageTooLargeError`); they were private classes of the extractor modules. Messages, codes and HTTP statuses are unchanged.
- `audiodoc.transcription.temp_files.temp_dir()` returns the private audio directory from the current settings.
- `scripts/check_changelog.py`, shared with the other repository and run by `make docs-check`, requires the sections of every changelog version to follow the order Added, Changed, Deprecated, Fixed, Removed, Security, without duplicates or unknown sections.

### Changed

- `requirements-lock.txt` is generated by `uv` and checked by `scripts/check_lock.py` as before.
- Renovate regenerates the lock with the `pip-compile` manager, leaves Python version changes to humans, updates tightly coupled packages together and no longer merges GitHub Actions, pre-commit hooks, build tooling, major, `0.x` and parser or network minor updates by itself.
- The pylint configuration checks only the docstring sections that are written, uses `max-try-statements = 1` and drops the `while_used` extension. Several findings in the code are fixed without changing behavior.
- pylint is pinned to 4.1.4.
- Magic string and byte values in the code are named constants, every `try` clause wraps a single statement and long functions are split into helpers. Behavior is unchanged.
- `scripts/coverage_gaps.py` is shared with bot-obormot and checked by `scripts/check_vendored.py`.
- Renovate refreshes the lock on the first day of each month (`renovate/pip-compile-refresh`); a human merges it. The generic lock maintenance job is off because it duplicated that branch.
- `build_parser` in the CLI module is public so that `scripts/check_docs.py` does not import a private name.
- Unit tests moved to the path that mirrors the production unit they cover (multi-unit test files were split, shared helpers went to `tests/support/`); tests of the project itself moved to `tests/unit/project/` and `tests/unit/scripts/`.
- Test functions and test modules need no docstring: pylint `no-docstring-rgx` exempts them and `D1` stays ignored for `tests/*`. This is technical debt that a later release removes. `AGENTS.md` records the rule.
- `scripts/vulture_whitelist.py` is removed. vulture runs without a whitelist; `ignore_names` lists two Protocol parameter names.
- The ruff ignores `FBT`, `TD002`, `TD003` and `FIX002` and the `ANN` and `ARG` ignores for tests are gone. Boolean parameters of `get_bool` and a few helpers are keyword-only, and the tests are annotated.
- `typings/pymupdf` is a minimal stub, so the PDF extractor needs no `Any` casts.
- The changelog sections of every version follow the same order in both repositories.
- pylint now checks every test module in both repositories (audiodoc no longer passes `--ignore-paths='^tests/unit/'`), and the ruff `PLR2004` and `SLF001` ignores for `tests/*` are gone. Literals compared in tests are local variables, fixtures use `@pytest.fixture(name=...)`, fakes that use no instance state are static or plain namespaces, and comparisons with empty literals use truthiness.
- Tests no longer touch private names: the Tesseract checks run through `ensure_ready`, image preprocessing through `recognize_pages`, the PDF DPI fallback through `extract_pdf`, the ZIP member guards through `validate_zip_archive` with archives whose central directory lies about sizes, and the queue sizes through `WorkQueue.slot`.
- Tests that check for an empty result compare it with an empty literal of the expected type (`expected_empty = []`, then `assert value == expected_empty, "..."`) instead of relying on truthiness, so a `None` or a value of another type no longer passes.
- `audiodoc.transcription.temp_files` resolves the temporary directory when it is used instead of at import, so importing the module no longer loads the settings.
- Fake Whisper models and native-tool stubs moved to `tests/support/whisper.py`; the lifespan shutdown test drives the public `lifespan` context manager instead of calling `__aenter__`/`__aexit__`.

### Removed

- `TEMP_DIR` and `DEFAULT_TEMP_DIR` in `audiodoc.transcription.temp_files`. Call `temp_dir()` or set `BACKEND_TEMP_DIR`.

### Security

- The lock resolves for Python 3.11.5 or newer, so it pins `soupsieve` 4.x instead of 2.10, which is affected by GHSA-mmhr-3c5m-f64f (denial of service in the descendant combinator). The `uv` migration had briefly pinned 2.10.

## [0.3.0] - 2026-11-21

Deprecated functionality is not supported starting with 0.3.0.

### Added

- pylint with every message enabled and all stable extensions, next to ruff and mypy. It runs in `make pylint`, `make check` and CI.
- `AGENTS.md` with the rules for LLM agents working in this repository.
- Python 3.14 classifiers and a Python 3.14 CI job.

### Changed

- Renovate replaces Dependabot version updates and opens and merges the dependency pull requests. Dependabot alerts stay enabled as a second source of vulnerability reports.
- The installer tests, documentation and CI no longer cover the 0.1.x layout.
- `get_home_dir()` derives the home variable and directory from the package name, so `env_readers.py` is identical in audiodoc and bot-obormot.
- `scripts/check_vendored.py` compares only the shared lint tables (`ruff`, `mypy`) and the files that are really shared; the Makefile and CI workflow stay project-specific.
- CI now runs the type, dependency, dead-code and import-contract gates, and the test matrix includes Python 3.14.
- Fixed the installer reading the latest release metadata from GitHub and a broken URL in one installer error message.

### Removed

- The `WHISPER_API_KEY` and `DOCUMENT_API_KEY` environment variables. Use `AUDIODOC_AUDIO_KEY` and `AUDIODOC_DOCUMENT_KEY`.
- The `app.py` module and the `uvicorn app:app` entry point. Use `audiodoc run`.
- The duplicate modules `audiodoc.common.logging_setup`, `audiodoc.common.log_filters` and `audiodoc.config.env`. Import `audiodoc.logging_setup`, `audiodoc.log_filters` and `audiodoc.env_readers` instead.
- The 0.1.x migration in `install.sh` and its CI job.

## [0.2.0] - 2026-11-12

### Added (CLI, Docker, and API errors)

- Added a command-line interface for application management.
- Added Docker and Docker Compose deployment.
- Added a stable `code` field to API error responses.
- Added CI smoke coverage for release-wheel installation and virtual environment upgrades.
- Added installer tests for HTTP release assets, version changes, and rollback after a failed offline doctor check.

### Changed

- Renamed the Python package and import namespace from `backend` to `audiodoc`.
- Renamed API key settings to `AUDIODOC_AUDIO_KEY` and `AUDIODOC_DOCUMENT_KEY`.
- Replaced the legacy installer interface with verified release-wheel installation and staged `--upgrade`.
- Replaced the `AUDIODOC_INSTALL_DIR` environment variable with `AUDIODOC_HOME`.
- Documented the legacy 0.1.0 directory upgrade path and rollback behavior.

### Deprecated

- Deprecated `WHISPER_API_KEY`; use `AUDIODOC_AUDIO_KEY` instead.
- Deprecated `DOCUMENT_API_KEY`; use `AUDIODOC_DOCUMENT_KEY` instead.
- Deprecated `uvicorn app:app`; use `audiodoc run` instead.

### Removed

- Removed the legacy installer flags `--latest`, `--nightly`, and `--yes`. The installer selects the latest stable release automatically.

## [0.1.0] - 2026-11-06

### Added

- FastAPI service for audio transcription and document text extraction.
- Authenticated transcription and document-processing endpoints.
- Bounded processing queues, readiness checks, and request-ID logging.
- audiodoc deployment examples, bot connection guide, and release installer.

### Fixed

- Document truncation reporting at exact text-budget boundaries and across extractors.
