# Changelog

All notable changes to this project are documented here.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

### Added

- `make lock` generates `requirements-lock.txt` with `uv pip compile`; releases younger than 14 days are skipped unless `LOCK_MIN_RELEASE_AGE_DAYS=0` is passed.
- Guidance on the assignment expression `:=` in `CONTRIBUTING.md`.

### Changed

- `requirements-lock.txt` is generated by `uv` and checked by `scripts/check_lock.py` as before.
- Renovate regenerates the lock with the `pip-compile` manager, leaves Python version changes to humans, updates tightly coupled packages together and no longer merges GitHub Actions, pre-commit hooks, build tooling, major, `0.x` and parser or network minor updates by itself.
- The pylint configuration checks only the docstring sections that are written, uses `max-try-statements = 1` and drops the `while_used` extension. Several findings in the code are fixed without changing behavior.
- `build_parser` in the CLI module is public so that `scripts/check_docs.py` does not import a private name.

## [0.3.0] - 2026-11-21

Deprecated functionality is not supported starting with 0.3.0.

### Removed

- The `WHISPER_API_KEY` and `DOCUMENT_API_KEY` environment variables. Use `AUDIODOC_AUDIO_KEY` and `AUDIODOC_DOCUMENT_KEY`.
- The `app.py` module and the `uvicorn app:app` entry point. Use `audiodoc run`.
- The duplicate modules `audiodoc.common.logging_setup`, `audiodoc.common.log_filters` and `audiodoc.config.env`. Import `audiodoc.logging_setup`, `audiodoc.log_filters` and `audiodoc.env_readers` instead.
- The 0.1.x migration in `install.sh` and its CI job.

### Changed

- Renovate replaces Dependabot version updates and opens and merges the dependency pull requests. Dependabot alerts stay enabled as a second source of vulnerability reports.
- The installer tests, documentation and CI no longer cover the 0.1.x layout.
- `get_home_dir()` derives the home variable and directory from the package name, so `env_readers.py` is identical in audiodoc and bot-obormot.
- `scripts/check_vendored.py` compares only the shared lint tables (`ruff`, `mypy`) and the files that are really shared; the Makefile and CI workflow stay project-specific.
- CI now runs the type, dependency, dead-code and import-contract gates, and the test matrix includes Python 3.14.
- Fixed the installer reading the latest release metadata from GitHub and a broken URL in one installer error message.

### Added

- pylint with every message enabled and all stable extensions, next to ruff and mypy. It runs in `make pylint`, `make check` and CI.
- `AGENTS.md` with the rules for LLM agents working in this repository.
- Python 3.14 classifiers and a Python 3.14 CI job.

## [0.2.0] - 2026-11-12

### Added (CLI, Docker, and API errors)

- Added a command-line interface for application management.
- Added Docker and Docker Compose deployment.
- Added a stable `code` field to API error responses.
- Added CI smoke coverage for release-wheel installation and virtual environment upgrades.
- Added installer tests for HTTP release assets, version changes, and rollback after a failed offline doctor check.

### Changed

- Renamed the Python package and import namespace from `backend` to `audiodoc`.
- Renamed API key settings to `AUDIODOC_AUDIO_KEY` and `AUDIODOC_DOCUMENT_KEY`.
- Replaced the legacy installer interface with verified release-wheel installation and staged `--upgrade`.
- Replaced the `AUDIODOC_INSTALL_DIR` environment variable with `AUDIODOC_HOME`.
- Documented the legacy 0.1.0 directory upgrade path and rollback behavior.

### Deprecated

- Deprecated `WHISPER_API_KEY`; use `AUDIODOC_AUDIO_KEY` instead.
- Deprecated `DOCUMENT_API_KEY`; use `AUDIODOC_DOCUMENT_KEY` instead.
- Deprecated `uvicorn app:app`; use `audiodoc run` instead.

### Removed

- Removed the legacy installer flags `--latest`, `--nightly`, and `--yes`. The installer selects the latest stable release automatically.

## [0.1.0] - 2026-11-06

### Added

- FastAPI service for audio transcription and document text extraction.
- Authenticated transcription and document-processing endpoints.
- Bounded processing queues, readiness checks, and request-ID logging.
- audiodoc deployment examples, bot connection guide, and release installer.

### Fixed

- Document truncation reporting at exact text-budget boundaries and across extractors.
